# 🎮 EmulatorJS

### EmulatorJS v4.2.3 — APK v4.3.6

O **EmulatorJS** é uma plataforma de emulação auto-hospedada baseada em padrões web modernos, como **JavaScript** e **WebAssembly (WASM)**.

O projeto oferece uma interface de alto desempenho para executar **cores do Libretro** diretamente no navegador, utilizando tecnologias web modernas e sem depender de hardware externo.

---

## 🚀 Principais recursos

### ⚡ Execução baseada em WebAssembly
Utiliza binários **WebAssembly** para processamento eficiente, baixa latência e alta precisão durante a emulação.

### 🎮 Compatibilidade multissistema
Suporta uma grande variedade de sistemas clássicos, incluindo:

- NES
- SNES
- Genesis / Mega Drive
- PlayStation 1
- Nintendo 64
- PSP
- Amiga
- Commodore 64
- E diversos outros sistemas compatíveis com os cores disponíveis.

### 💾 Save State
Sistema de gerenciamento de estado que permite:

- Criar Save States
- Carregar estados salvos
- Persistir dados localmente
- Trabalhar com blobs de estado

### 🌎 Localização
Suporte a múltiplos idiomas, com tradução e detecção do sistema configuradas de acordo com o ambiente.
